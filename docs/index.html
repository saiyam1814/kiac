Kubernetes.
Every node, its own VM.

Local clusters on Apple silicon where each node boots in its own lightweight virtual machine. No Docker Desktop. No QEMU. Metrics and storage included.

Get started View on GitHub

Why kiac

Batteries included. Actually.

Everything you reach for in the first five minutes of a local cluster is already there.

🔒

Hardware-grade isolation

Each node is one lightweight VM on Apple's Virtualization framework - real kernels, real cgroups, not namespaces sharing a daemon.

📊

Metrics out of the box

kubectl top nodes works the moment the cluster is up. metrics-server ships by default, preconfigured.

💾

PVCs that just bind

A default StorageClass backed by local-path-provisioner is installed on create. Claim storage like on a real cluster.

🌐

Direct networking

Every node gets an IP your Mac can reach. Hit NodePorts directly - no port-mapping flags, no tunnels.

🧱

Multi-node, day one

--workers 2 gives you a real topology: scheduling, cross-node pod networking, node failures you can practice on.

⚖️

LoadBalancer included

MetalLB ships by default, pooled on node IPs. type: LoadBalancer gets a real EXTERNAL-IP your Mac can curl.

🍎

Native stack

One Swift runtime from Apple, one Go binary from us. No Docker Desktop, no Lima, no QEMU in between.

Install

Three commands to a cluster.

1 · Install the runtime

Grab apple/container 1.0 (signed pkg from Apple). Requires an Apple silicon Mac; macOS 26+ for multi-node.

2 · Install kiac

go install github.com/saiyam1814/kiac@latest

Then check your setup: kiac doctor

3 · Create

kiac create cluster --workers 2

Kubernetes 1.32-1.36, then kubectl get nodes and you are flying.
