CLI reference

Every command and flag, straight from the source. kiac <command> --help shows the same information in your terminal.

kiac create cluster

Create a Kubernetes cluster of lightweight-VM nodes.

kiac create cluster
kiac create cluster --name dev --workers 2
kiac create cluster --memory 8G --cpus 4
kiac create cluster --distro k3s --workers 1
kiac create cluster --cni cilium --kernel full
kiac create cluster --config cluster.yaml
FlagDefaultDescription
--configcluster config YAML (see Config file); flags set explicitly on the command line override file values
--namedevcluster name (lowercase letters, digits, dashes)
--workers0number of worker nodes (control plane is untainted when 0)
--k8s-version1.36Kubernetes version (1.36, 1.35, 1.34, 1.33, 1.32), for either distro
--distrokubeadmKubernetes distribution per node VM: kubeadm (kindest/node), or k3s (rancher/k3s: sqlite datastore, bundled local-path storage and metrics-server; kiac-lb handles LoadBalancers). See k3s distro
--imagenode image (overrides --k8s-version)
--cnikindnetpod network: kindnet, cilium (needs --kernel full and the cilium CLI), or none (bring your own). kubeadm distro only; the k3s path always gets kindnet
--kernelcustom node kernel: full (downloads the published kiac kernel with VXLAN/eBPF/br_netfilter, cached in ~/.kiac/kernels/) or a path to an arm64 boot Image. See Cilium & the full kernel
--cpus4vCPUs per node VM
--memory2Gmemory per worker VM (idle workers use a few hundred MB)
--cp-memory4Gmemory for the control-plane VM (etcd, apiserver, and on single-node clusters every addon)
--no-metricsfalseskip installing metrics-server
--no-storagefalseskip installing the local-path default StorageClass
--no-lbfalseskip installing kiac-lb (type: LoadBalancer support)
--no-edge-proxyfalseskip the node-local edge proxy that fixes large TCP uploads through NodePorts and LoadBalancers
--observabilityfalseinstall Prometheus + Grafana + node-exporter, Grafana on a LoadBalancer IP
--gatewayfalseinstall Gateway API CRDs + Traefik with a ready-to-use GatewayClass and Gateway
--wait5mtimeout for nodes to become ready

Version resolution: a minor like 1.34 uses kiac's digest-pinned node image (kindest/node, or rancher/k3s with --distro k3s); an exact patch matches the pin when it is the pinned patch, otherwise falls back to the matching upstream tag unpinned.

--distro and --kernel are CLI flags only for now; they are not config file keys yet.

kiac delete cluster

Delete a cluster's node VMs and its kubeconfig entries.

kiac delete cluster --name dev
FlagDefaultDescription
--namedevcluster name

kiac get clusters

List kiac clusters (alias: kiac get cluster). STATUS shows running nodes out of total, e.g. 3/3 running, or 0/3 stopped when the VMs are halted (typically after a reboot; kiac resume cluster brings them back).

kiac get clusters
kiac get clusters -o wide    # adds K8S-VERSION and CREATED columns
kiac get clusters -o json    # machine-readable, always a JSON array
FlagDefaultDescription
-o, --outputoutput format: wide or json

kiac get nodes

List the node VMs of one cluster (NODE, STATUS, IMAGE).

kiac get nodes --name dev
FlagDefaultDescription
--namedevcluster name

kiac stop node

Stop a node VM to test real node failure: the node goes NotReady and its pods reschedule. Accepts the short node name (worker-1, control-plane) or the full container name (kiac-dev-worker-1). Stopping the control plane of a single-node cluster is refused; on multi-node clusters it proceeds with a warning. See Node chaos.

kiac stop node worker-1
kiac stop node worker-2 --name staging
FlagDefaultDescription
--namedevcluster name

kiac start node

Start a previously stopped node VM. Idempotent: on an already-running node the boot is simply skipped. The node's IP may change across restarts; the kubelet re-registers with the new address on its own, and kiac-lb re-points any LoadBalancer ingress IP pinned to the old address on its next pass. Note one known host-to-node TCP limitation for restarted VMs.

kiac start node worker-1
kiac start node worker-2 --name staging
FlagDefaultDescription
--namedevcluster name

kiac resume cluster

Boot a stopped cluster's VMs and heal it after a host reboot. A reboot (or container system stop) halts every node VM, and vmnet hands out fresh IPs on the next boot; resume restarts the VMs, rewrites the control-plane address everywhere it is pinned (apiserver cert, kubeconfigs, kube-proxy), and waits for the nodes to come back Ready. Safe to re-run; a running cluster is a no-op. kubeadm clusters only. See Reboots & resume.

kiac resume cluster --name dev
FlagDefaultDescription
--namedevcluster name
--wait5mhow long to wait for boot, API server, and node readiness

kiac load image

Copy images from the apple/container local image store into the containerd instance of every node VM, so pods can run them without pushing to a registry. Build first with container build -t myapp ., and set imagePullPolicy: IfNotPresent (or Never) in your pod spec.

kiac load image myapp:dev --name dev
kiac load image api:dev web:dev --name dev    # several at once
FlagDefaultDescription
--namedevcluster name

kiac doctor

Check that this Mac can run kiac clusters: macOS version (26+ for multi-node), apple/container CLI 1.0.0+, the container system service, kubectl, and Apple silicon.

kiac doctor
kiac doctor --fix
FlagDefaultDescription
--fixfalseattempt to fix failed checks (starts the container system service)

kiac ui

Open a local console to create and manage clusters. Binds to 127.0.0.1 and opens your browser. See Dashboard.

kiac ui
kiac ui --port 0    # pick a free port
FlagDefaultDescription
--port5180port for the local console (0 picks a free one)

kiac completion

Generate a shell completion script for bash, zsh, fish, or powershell.

# zsh
kiac completion zsh > $(brew --prefix)/share/zsh/site-functions/_kiac
# start a new shell; if completions stay off, add to ~/.zshrc first:
#   autoload -U compinit; compinit

# bash (needs the bash-completion package: brew install bash-completion@2)
kiac completion bash > $(brew --prefix)/etc/bash_completion.d/kiac

# fish
kiac completion fish > ~/.config/fish/completions/kiac.fish

# try it in the current shell without installing anything
source <(kiac completion zsh)
