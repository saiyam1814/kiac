kiac: Kubernetes in Apple Containers

kiac creates local Kubernetes clusters on Apple silicon where every node boots as its own lightweight virtual machine, powered by Apple's open-source container runtime. No Docker Desktop, no Lima, no QEMU.

What you get

One command boots a real multi-node cluster from the standard kindest/node image, with the first-five-minutes toolkit already installed:

  • One lightweight VM per node. Each node has its own kernel, kubelet, cgroups, and IP. The isolation boundary between nodes is the hypervisor, not Linux namespaces.
  • Metrics. metrics-server ships preconfigured; kubectl top nodes works out of the box.
  • Storage. A default StorageClass backed by local-path-provisioner, so PVCs just bind.
  • LoadBalancer. kiac-lb, a tiny controller inside the control-plane VM, assigns node IPs to type: LoadBalancer Services in about two seconds; the edge proxy keeps large external uploads flowing through NodePorts and LoadBalancers. See Networking.
  • Two distros. kubeadm on kindest/node by default, or --distro k3s for rancher/k3s as PID 1 per VM: a 2-node cluster in under a minute. See k3s distro.
  • Cilium and eBPF. --cni cilium --kernel full boots the nodes on a published, sha-pinned kernel build and drives the official Cilium installer. See Cilium & the full kernel.
  • Clusters survive reboots. kiac resume cluster boots the VMs back up after a host reboot and heals everything the new IPs broke. See Reboots & resume.
  • Optional observability. --observability installs Prometheus and Grafana with dashboards already provisioned. See Observability.
  • Optional Gateway API. --gateway installs the Gateway API CRDs and Traefik with a ready-to-use Gateway. See Gateway API.
  • Node chaos. kiac stop node / kiac start node stop and restart a real node VM. See Node chaos.
  • A local dashboard. kiac ui opens a web console with cluster cards, live resource bars, a kubectl console drawer, and a create form. See Dashboard.

Requirements

RequirementDetail
Apple silicon Macarm64 only
macOS 26+needed for multi-node networking; single-node may still work on older macOS
apple/container 1.0.0+signed pkg installer from Apple; skip incompatible 1.2.0 and use 1.2.1+
kubectlany recent version

Install

brew install --cask saiyam1814/tap/kiac

Prefer Go, or building from source:

# With Go
go install github.com/saiyam1814/kiac@latest

# From source
git clone https://github.com/saiyam1814/kiac && cd kiac && make build

Verify your setup

kiac doctor

kiac doctor checks the macOS version, the apple/container CLI, the container system service, kubectl, and the CPU architecture. If the container system service is stopped, kiac doctor --fix starts it for you (kiac also starts it automatically on create).

First cluster

kiac create cluster --name dev --workers 2

That boots three lightweight VMs (one control plane, two workers), initializes Kubernetes with kubeadm, installs the kindnet CNI plus the default addons, and merges the kubeconfig into ~/.kube/config as context kiac-dev.

kubectl get nodes
kubectl top nodes    # native metrics, give it ~60s to scrape
kiac verify cluster --name dev

kiac verify cluster is read-only and checks the complete path from each node VM and its services through Kubernetes readiness, DNS, storage, metrics, networking helpers, optional addons, and the Mac-to-API connection. Use -o json for a stable automation schema and a nonzero exit when a required check fails.

Supported Kubernetes versions are 1.32 through 1.36 (pinned image digests); 1.36 is the default. Pick one with --k8s-version 1.34, on either distro. In a hurry? kiac create cluster --distro k3s --workers 1 is Ready in well under a minute.
